# sunnykumar.work

Plain HTML/CSS portfolio, hosted on GitHub Pages. No build step.

```
index.html                     Landing (three case-study titles)
about.html                     About / CV
work/ai-campaign-manager.html  01 Campaigns, now with a brain
work/cloud-platform.html       02 Cloud, minus the chaos
work/identity-access.html      03 Access, without the headache
css/site.css                   All styles; colours at the top
js/site.js                     Swaps grey placeholders for real images
assets/                        Put Sunny-Kumar-Resume.pdf here
images/                        Case-study images (names below)
CNAME, 404.html
```

## Images
Each grey box shows what belongs there until the file exists. Save with these exact names:

- images/campaign/  hero.jpg, iq-reach.jpg, uclm.jpg
- images/cloud/     hero.jpg, user-lifecycle.jpg, field-level-test.png, assurance-funnel.jpg,
                    kms-key-types.png, cspm-findings-after.jpg, cost-analyser-ia.jpg
- images/iam/       hero.jpg, aws-audit.png, legacy-model.png, user-to-role-flow.gif,
                    trust-vs-delegation.gif, conditions-flow.gif, access-analyzer.jpg

Keep each under ~500 KB. Redact names, emails and client data first.

## Resume
Add your PDF as assets/Sunny-Kumar-Resume.pdf. The links on the landing and About pages point there.

## Updating the live site
In the GitHub repo: Add file → Upload files. A file with the same name replaces the old one.
